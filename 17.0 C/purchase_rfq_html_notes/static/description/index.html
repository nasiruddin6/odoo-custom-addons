Purchase / RFQ HTML Notes

FSN Analysis Report helps businesses categorize inventory into Fast-moving, Slow-moving, and Non-moving items based on consumption and sales patterns. This report enables better stock optimization, reduces holding costs, improves demand planning, and supports data-driven inventory decisions for efficient warehouse and supply chain management.

Key Features:

  1. Global RFQ/PO Note Configuration

    Configure a single HTML-formatted note from Purchase Settings

    Note applies globally to all RFQs and Purchase Orders

  2. Rich-Text HTML Editor

    WYSIWYG editor for creating formatted notes

    Support for bold, italic, lists, links, and other HTML formatting

  3. Automatic Note Display on Forms

    Note automatically appears on RFQ and Purchase Order forms

    Displayed via dedicated field in the form view

  4. PDF Report Integration

    Note included in printed RFQ/PO PDF reports

    Rendered through QWeb report templates

  5. HTML Preservation

    HTML formatting preserved in printed documents

    Rendered through QWeb report templates

  6. Multi-Company Support

    Company-specific notes

    Each company can maintain its own RFQ/PO note

  7. Access Rights Integration

    Follows standard Purchase module permissions

    No additional security configuration required

Description

1. Global RFQ/PO Note Configuration under General Setting > Purchase > Purchase Notes

2. When create RFQ / purchase order auto load setting value on Purchase Notes tabs

3. Shown on PDF Report of RFQ / Purchase Order Printed Document
