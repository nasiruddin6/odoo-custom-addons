# Property Management (Rent, Lease, and Sales)

Manage properties and units, then run rental, lease, and sale contracts with invoicing, bookings, and maintenance.

Depends on contacts, CRM, sales, HR, and maintenance.

## What it does

- Properties and units, including a wizard to create units in bulk.
- Separate flows for **Renting**, **Leasing**, and **Selling**: contracts, invoices, and payments.
- Contract settlement with a printable settlement report.
- Sale bookings, payment plans, and wizards for EOI and booking payments.
- Contacts for landlords, brokers, tenants, and customers.
- CRM property leads, opportunities, and site visits.
- Maintenance requests linked to properties.
- Configuration for property types, cities, amenities, furnish types, utilities, durations, and agreement templates.

## How to check the UI

1. Open the **Properties** app.
2. **Property Management → Property** and **Unit**: create a property, then units (use the unit wizard).
3. **Renting**, **Leasing**, and **Selling → Contracts**: open a contract, change its state, and try invoice and settlement actions.
4. **Selling → Bookings** and **Payment Plans**: create a booking and a plan, then run the payment wizards.
5. **Leads → Property Leads** and **Visiting**: create a lead and a visit.
6. **Maintenance → Requests**: create a request and link it to a property or unit.
7. Open **Configuration** and confirm master data menus (types, cities, amenities, utilities, agreement templates) open and save records.
