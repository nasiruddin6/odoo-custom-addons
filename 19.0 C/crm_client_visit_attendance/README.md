# CRM Client Visit and Attendance

Plan client visits, check in and out with location, and record attendance from those visits.

Depends on CRM, HR, and attendance.

## What it does

- **My Visits** for the current user and **All Visits** for managers.
- Check-in and check-out on a visit, with location.
- **Visit Attendance** records created from those visits.
- Visits shown from CRM leads and contacts.
- A visit analysis report.
- A mail template for visit confirmation.

Users need the Client Visit User or Manager group. Managers see all visits, attendance, and reports.

## How to check the UI

1. Give the user **Client Visit User**. Give a second user **Client Visit Manager**.
2. As the user, open **CRM → Client Visits → My Visits** and create a visit (partner, date, assignee).
3. Use **Check In** and **Check Out** and confirm the times and location are stored.
4. As the manager, open **All Visits** and **Visit Attendance** and confirm the same visit appears.
5. Open **Client Visits → Reports** and check the analysis view.
6. Open a CRM lead and a contact and confirm the visit smart button or tab lists the visit.
